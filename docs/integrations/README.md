# Интеграции MoreOps

MoreOps объединяет и оркестрирует проверенные индустриальные инструменты DevOps без необходимости изобретать их заново:

- **CI/CD**: Jenkins (`Jenkinsfile`), GitHub Actions, GitLab CI
- **GitOps**: Argo CD (рекомендуемый дефолт), Flux CD
- **Мониторинг и Observability**: Prometheus Operator (`ServiceMonitor`), Grafana Dashboards, Loki, Tempo
- **Безопасность и секреты**: HashiCorp Vault, External Secrets Operator (ESO), Trivy
- **Хранилище и бэкапы**: MinIO, S3 (Yandex Cloud, VK Cloud, Selectel, AWS), Velero
- **Инфраструктура как код (IaC)**: OpenTofu, Terraform, Ansible
