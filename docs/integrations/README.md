# Integrations

MoreOps seamlessly integrates with modern DevOps tools without reinventing them:

- **CI/CD**: Jenkins (`Jenkinsfile`), GitHub Actions, GitLab CI
- **GitOps**: Argo CD, Flux CD
- **Monitoring**: Prometheus Operator (`ServiceMonitor`), Grafana Dashboards, Loki, Tempo
- **Security**: HashiCorp Vault, External Secrets Operator, Trivy
- **Storage**: MinIO, S3 (Yandex Cloud, VK Cloud, Selectel, AWS), Velero
- **IaC**: OpenTofu, Terraform, Ansible
